可选收尾：分档上下文缓存 + 配方一致性单测。生成语义与数据契约完全不变（11 个 dump 指纹逐位一致）。

分档缓存（按用户决策：≤2k 双槽、≥4k 不缓存）：

- 新增 `MapContextCache`：1024/2048 保留 **2 槽 LRU**（A→B→A 切图免重建），4096/8192 **0 槽**（生成后不保留上下文，切图重跑管线，结果逐位一致只是慢）
- 0 槽的 `Put` 只返回 false、不清空已有缓存（生成一张大图不会把之前缓存的小图清掉）
- 解决「两份 8192 上下文各约 800 MB、与 V2.x 内存优化冲突」的问题
- `WorldTerrainGenerator` 重构：删单槽 `lastContext`，改用 `contextCache`；`GenerateFromRecipe` 命中走缓存；`ApplyCachedToEarth` 改为接收 ctx 参数
- **导出不依赖缓存**：≥4096 无缓存上下文时，`ExportCurrentMap` 用当前配方即时重建一份临时上下文供导出，用完即释放（不进缓存、不常驻）。大分辨率点导出会明显卡顿，但只在用户显式触发时发生且日志会说明

配方一致性单测下沉到离线校验台：
