行星渲染改造步骤 3：大气单次散射 + 地表巡回模式。生成语义与数据契约完全不变（11 个 dump 指纹逐位一致）。

大气单次散射（升级现有球壳，不新增层）：

- `AtmosphereGlowShader` 从 V3.2 的纯 Fresnel 光环改为**球壳 raymarch 单次散射**：指数密度、瑞利 + 米氏相位、朝太阳方向再求一次光学厚度算透射率
- 实测修正：密度改回「地表最密」（原写反成地表最稀）、散射改用 Beer-Lambert + 软压缩、新增 `_ScatterScale`（默认 3.0）。修正前球内散射只有 2~7% 亮度、几乎看不见，修正后球内天空明显偏蓝（B-R 124.4）、球外不过曝
- 深度纹理无效时不再把散射整片砍掉（对无效深度返回极大值，不遮挡）
- 散射随昼夜 / 季节（`SunLightController`）自然变化：日出日落偏暖、正午偏白
- **深度遮挡**：采样 `_CameraDepthTexture` 把积分终点钳到视线碰到地表的位置，大气不会画到星球前面、山体能正确挡住；由 `AtmosphereGlow` 自动给主相机开 `DepthTextureMode.Depth`
- **Cull Off**：球壳两面都画，由 raymarch 求射线与球壳交点区间；相机在球内（巡回模式）时从相机起积分
- 参数（散射色 / 密度 / 步数 / 太阳强度 / 瑞利 / 米氏 / 曝光）挂在 `AtmosphereGlow` 组件上可调；V3.2 的边缘辉光保留为可单独调节的增强项
- 「半分辨率」用降 raymarch 步数（默认 12）近似，未做离屏半分辨率 RT

地表巡回模式（站在地表抬头看天）：

- 新增 `SurfaceRover`：把相机放到**星球表面之上、大气球壳之内**（默认 1.03R）贴地表漫游，`CameraController` 通过 `SetExternalControl` 交出控制权，两套相机逻辑不打架
- 实测修正：首版把相机放在 0.985R（星球网格内部），因地表 shader 是 `Cull Back` 导致整片地表被剔除、无法观察；同时贴地表时 near clip 0.3 会裁掉脚下。现改为地表之上 + 临时把 near clip 调到 0.02（退出恢复）
- 半径用星球自身网格的世界半径，避免 `Renderer.bounds` 被子物体影响
- 操作：W/S 前进后退、A/D 平移、右键拖拽转视线、滚轮调离地高度、Shift 加速
- right-bar 新增「地表巡回」按钮，进入 / 退出；退出后环绕视角自动恢复
- 大气散射在「大气层内」与「大气层外」的积分路径不同，此模式用于直观对比

验证：

- 编译门 0 错误；Unity 2022.3.62f3c1 `COMPILE_OK`，完整构建 `BUILD_OK`，shader 变体编译无 error
- 11 个地形 dump 与基线逐位一致
- **球外 / 球内离屏渲染对比图**（`V3.4.0_atmosphere_compare.png`，左球外右球内）：99.9% 像素差异，球内明显更蓝（B-R 99.1 vs 球外 50.0），确认散射内外不同
